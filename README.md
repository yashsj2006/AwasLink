# AwasTrack

AwasTrack is a simple city housing tracker made for everyday people, government teams, and jury members. It explains housing projects in plain language and shows whether a home project is safe, fair, and ready for families to live in.

## What this project tells people

This app helps answer one simple question:

Is this housing project ready for families to move in safely with basic services working?

It brings together key information in one place:

- which families are eligible and checked
- whether construction is progressing on time
- whether water, electricity, roads, toilets, and other daily needs are ready
- whether the project has risks or problems that need attention
- whether families are ready to move into their homes

## Easy language used in the project

The project avoids technical terms and uses clearer wording such as:

- project status = how ready the project is
- family verification = checking whether a family is eligible
- basic services = water, electricity, roads, drainage, waste, and other daily needs
- risk score = a simple warning sign showing whether something may go wrong

## Who can use it

- citizens who want to understand housing work in their area
- local government officers tracking progress and issues
- developers and builders reviewing readiness
- jury members reviewing the project in a clear, easy-to-follow way

## Run it locally

```bash
npm install
npm run dev
```

Then open the local URL shown in the terminal.

## Build for production

```bash
npm run build
```

This project is built with React and Vite and is designed to be simple, clear, and easy to explain to the public.
